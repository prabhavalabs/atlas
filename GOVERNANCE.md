# Governance

Atlas is stewarded by Prabhava Labs as an open-source public-interest project.

## Decision making

- Maintainers accept routine fixes and documentation improvements through pull-request review.
- Material product, architecture, security, data-source, licensing, or operational changes require an issue or discussion before implementation.
- Durable technical decisions are recorded as ADRs under `docs/decisions/`.
- Public safety, evidence traceability, source rights, accessibility, and one-maintainer operability take precedence over feature breadth.

Prabhava Labs maintainers make final release and safety decisions while the initial maintainer group is small. Governance will be revisited when sustained external maintainers have demonstrated responsibility across multiple releases.

## Releases

Releases require passing tests, migration checks, documentation, attribution review, security scanning, backup/restore evidence, and the phase-specific checklist. No contributor can publish directly without maintainer review.

## Changes to governance

Governance changes use a public pull request with rationale and a reasonable review period. Emergency security actions may occur privately first and be documented after disclosure is safe.
